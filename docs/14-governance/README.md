# Governance

This folder consolidates governance artifacts and decision records.

- `architecture-decisions/` — Architectural Decision Records (ADRs). This is the canonical home of the ADR corpus (`ADR-001`…`ADR-030`); the prior `docs/09-decisions/` location is retired (see `docs/15-audits/ADR_INTEGRITY_RESTORATION_2026-07-16.md`).
- `decision-records/` — Other governance decisions and records (create as needed).

Note: The canonical workflow runner is in `.claude/workflows`. This README should remain a lightweight guide; the framework is authoritative.
